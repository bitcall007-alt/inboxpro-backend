Backend URL (Railway)
🚀 Despliega el backend en Railway y pega aquí la URL que te dé. Ej: https://inboxpro-backend.up.railway.app
Guía de deploy en Railway — paso a paso
1
Crea cuenta en Brevo
brevo.com → gratis → Settings → SMTP & API → Genera SMTP key → copia host, user y password
2
Sube el backend a GitHub
Crea repo privado → sube los archivos del backend (server.js, package.json, railway.json)
3
Deploy en Railway
railway.app → New Project → Deploy from GitHub → selecciona tu repo → Railway detecta Node.js automáticamente
4
Configura variables de entorno en Railway
SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_USER=tu@email.com
SMTP_PASS=tu_api_key_brevo
API_SECRET=clave_secreta_larga
ALLOWED_ORIGINS=https://tu-frontend.netlify.app
5
Copia la URL de Railway y pégala arriba
Railway te da una URL tipo: https://inboxpro-xxxxx.up.railway.app — pégala en el campo Backend URL
